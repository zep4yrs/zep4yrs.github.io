六个方向six directions

工坊覆盖六个技术方向，从桌面到 Web，从安全到教学，再到游戏和基础设施。每个方向都有对应的项目落地。

SIX · 全方向

能力矩阵capability matrix

N°01 · DESKTOP

桌面开发desktop

跨平台桌面应用，Rust + Tauri 为主。重视本地体验、离线可用、系统级集成。BlueTidy、LanNook 是这个方向的代表。

Rust · Tauri · React

N°02 · WEB

Web 工具web tools

在线工具，零安装即用。覆盖 CTF、教学、可视化场景。CTF 乾坤袋、CryptoVis、StructVis 都在这个方向。

JavaScript · Browser · Canvas · WebGL

N°03 · SECURITY

安全工程security

渗透测试自动化、CTF 工具、安全教学。把安全流程从手工操作变成可复现的工程。Polaris、CTF 乾坤袋、零号告警覆盖这个方向。

Pentest · CTF · Automation

N°04 · TEACHING

教学可视化teaching

把抽象概念变成可操作的动画。保持一致教材章节，跟着课本走，不自说自话。CryptoVis、StructVis 是这个方向的核心。

Visualization · Animation · Textbook-aligned

N°05 · GAME

游戏化学习game learning

Godot 4 + C# 开发 Steam 单机游戏，在虚拟场景里走完整专业流程。零号告警是第一个，扮演网络安全中心老师处理告警。

Godot 4 · C# · Steam · Serious Game

N°06 · INFRA

基础设施infrastructure

自动化管线、构建工具、内部工具链，支撑项目从设计到发布的全流程。不对外发布，但所有项目都跑在上面。

CI/CD · Build Tools · Automation
